# Repository agent guidance

For work on the Lumina cognitive harness audit, follow [`docs/COGNITIVE_HARNESS_AUDIT_METHOD.md`](docs/COGNITIVE_HARNESS_AUDIT_METHOD.md) as the standing procedure. The method applies across turns and restarts: retain the audit objective, maintain its evidence and status, and do not treat a small code change or a restart as completion.

Before changing files, inspect the current Git state and the latest audit report entry. Preserve unrelated and untracked user data. Keep audit fixes scoped, trace each defect to its cause, and record what is locally verified versus what is verified in a live Lumina process.
